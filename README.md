# Carrinho vs IA — teste de feedback tátil com DualSense

## Quer testar?

Estou convidando pessoas para experimentar este joguinho e compartilhar como foi a experiência. O projeto explora formas de usar feedback tátil (vibração) em um controle, com interesse em acessibilidade e em como diferentes pessoas percebem esses sinais.

**Baixe o jogo:** [carrinho-vs-ia-corrigido.zip](./carrinho-vs-ia-corrigido.zip)

## Recomendação para o controle

Se você tiver um controle **DualSense (PS5)**, conecte-o ao computador **por cabo USB** antes de iniciar o jogo. A conexão por cabo é recomendada para este teste, especialmente para que o controle seja reconhecido e o feedback tátil funcione da forma esperada.

O comportamento pode variar conforme o computador, o navegador, o sistema operacional e a forma de conexão. Se não tiver um DualSense, ainda pode testar o jogo, mas talvez não consiga avaliar a vibração.

## Como participar

1. Baixe o arquivo ZIP acima.
2. Extraia os arquivos para uma pasta no computador.
3. Conecte o DualSense por USB, se for usá-lo.
4. Abra o jogo pelos arquivos extraídos e experimente.
5. Observe se os sinais de vibração ajudam a entender o que acontece durante a partida.
6. Envie seu feedback à pessoa que compartilhou o jogo com você.

## O que observar

- Foi fácil iniciar e entender o objetivo?
- Os sinais de vibração foram perceptíveis?
- Você conseguiu associar cada vibração a algo que aconteceu no jogo?
- A vibração ajudou, atrapalhou ou não fez diferença?
- Algo ficou confuso, desconfortável ou difícil de usar?
- O que você mudaria?

Não é necessário ter conhecimento técnico. Relate sua experiência com suas próprias palavras. Se possível, diga também se usou DualSense por cabo, outro controle ou apenas teclado e mouse.

## Sobre o projeto

Este é um projeto experimental para estudar como uma inteligência artificial pode formular padrões de feedback tátil para controles. A proposta é explorar possibilidades de interação e acessibilidade por meio de sinais de vibração. Os resultados deste teste são exploratórios e dependem da experiência de cada participante e do equipamento utilizado.

## Aviso

Este projeto está em desenvolvimento e pode apresentar falhas ou diferenças de funcionamento entre dispositivos. Faça pausas ou interrompa o uso se a vibração causar desconforto.

## Feedback

Depois de testar, compartilhe suas observações com a pessoa que enviou o jogo. Comentários sobre facilidade de uso, clareza dos sinais e compatibilidade do controle são especialmente úteis.
